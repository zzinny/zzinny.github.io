Unending Rock

2026, JavaScript, color

A Graphical User Interface (GUI) refers to visual symbols designed to enable humans to control computers. To create a new GUI, I drew a rock using computer code. Unlike a real-world rock, this virtual rock bends and distorts according to its own set of rules and external inputs (mouse position), so that it always remains in an unfinished state. Technology shapes its form and meaning through the interaction between the internal and the external, being neither absolute nor independent.
